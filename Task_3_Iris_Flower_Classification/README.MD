# Iris Flower Classification

This project is completed as Task 3 of the CodSoft Data Science Internship.

## Objective

The objective of this project is to build a Machine Learning model that classifies Iris flowers into their correct species using sepal and petal measurements.

## Dataset

The Iris dataset was downloaded and used in this project. It contains three flower species:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

The input features are:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Project Workflow

1. Import required libraries.
2. Loaded the downloaded `Iris.csv` dataset.
3. Checked dataset columns, shape, and missing values.
4. Visualized flower species and petal measurements.
5. Split the dataset into training and testing data.
6. Trained a Random Forest Classifier model.
7. Evaluated the model using accuracy, classification report, and confusion matrix.
8. Predicted the species of a new flower.
