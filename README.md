# 📊 CodSoft Data Science Internship Projects

This repository contains the Data Science and Machine Learning projects completed during my **CodSoft Data Science Internship**.

The projects demonstrate practical implementation of the complete Machine Learning workflow, including **data preprocessing, exploratory data analysis, visualization, feature selection, model training, prediction, and model evaluation**.

---

## 🚀 Projects

### 🚢 Task 1 – Titanic Survival Prediction

A Machine Learning classification project that predicts whether a passenger survived the Titanic disaster based on passenger information such as age, gender, passenger class, fare, and embarkation port.

**Key Concepts:**

* Data Cleaning
* Missing Value Handling
* Exploratory Data Analysis
* Data Visualization
* Feature Selection
* Categorical Encoding
* Train-Test Split
* Classification
* Model Evaluation

**Algorithm Used:** Random Forest Classifier

**Model Accuracy:** Approximately **81.56%**

📁 `Task_1_Titanic_Survival_Prediction`

---

### 🌸 Task 3 – Iris Flower Classification

A Machine Learning classification project that predicts the species of an Iris flower using its sepal and petal measurements.

The model classifies flowers into:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

**Key Concepts:**

* Dataset Exploration
* Data Visualization
* Feature Selection
* Train-Test Split
* Classification
* Confusion Matrix
* Classification Report
* New Sample Prediction

**Algorithm Used:** Random Forest Classifier

📁 `Task_3_Iris_Flower_Classification`

---

### 📈 Task 4 – Sales Prediction

A Machine Learning regression project focused on predicting product sales using advertising expenditure across different marketing channels.

**Key Concepts:**

* Exploratory Data Analysis
* Correlation Analysis
* Data Visualization
* Feature Selection
* Regression Modeling
* Prediction
* Model Evaluation

📁 `Task_4_Sales_Prediction`
